# Contributing / 贡献说明

Thank you for helping improve this engineering learning resource. Please open a GitHub Issue for a correction, question, or suggestion.

感谢帮助改进这份工程学习资料。发现错误、有疑问或有教学建议时，请提交 GitHub Issue。

## What makes a useful report / 有帮助的反馈

- Identify the page section and language (Chinese or English).
- For a factual correction, cite the source page and provide the supporting value or wording.
- For a DOE interpretation, explain the reasoning and distinguish source facts from recommendations.
- For a display problem, include browser/device and screen size if known.
- Do not present estimates or interpolations as measured results. The interactive explorer labels them explicitly.

请注明页面章节及语言。事实更正请提供资料页码和对应内容；DOE 解读建议请说明依据，并区分资料事实与建议。显示问题可附浏览器、设备和屏幕尺寸。不要把估算或插值写成实测结果。

## Privacy and source files / 隐私与原始资料

Do not include confidential company, customer, product, process, or personal information in issues. Do not upload the original PDF, extracted source figures, or private training files. The published guide keeps source page references so readers can trace the educational explanations without distributing those files.

请勿在 Issue 中披露公司、客户、产品、工艺或个人机密信息，也不要上传原始 PDF、提取的资料图片或内部培训文件。网站通过标注资料页码保留教学内容的追溯关系，不分发这些原始文件。

## Content principles / 内容原则

- Keep every reported value traceable to the cited source page.
- Mark information absent from the source as not provided.
- Clearly label any newly introduced explanation, estimate, or illustrative example.
- Do not claim a factor is statistically significant or confirmed unless the cited analysis supports that claim.
- Preserve the distinction between DOE inputs (X: Timing, Temperature, Pressure) and the measured response (Y: Volume).

所有资料数值须能追溯到所引页码；资料未载明的信息应标注未提供；新增解释、估算或示例必须明确标记。除非所引分析支持，不要声称因素显著或结果已确认。请保留 DOE 输入 X（Timing、Temperature、Pressure）与测量响应 Y（Volume）的区别。
